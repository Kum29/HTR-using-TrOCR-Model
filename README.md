# HTR-using-TrOCR-Model
HTR (Handwritten Text Recognition). Converting handwritten notes to readable text using 
The TrOCR (Transformer-based Optical Character Recognition) basic Encoder-Decoder Model

Step 1. Image pre-processing-> converting a normal image to a computer-readable image.
Step 2. Using pre-trained models to generate predicted text-> Didn't perform any fine-tuning, but most of the work went into decreasing delays/ making it efficient.
Step 3. Post-processing: As the generated text is not quite accurate, this step allows correcting any spelling mistakes.
